# Altitude KYB walkthrough log

Phase 0 of the plan. Source: app.altitude.xyz, observed {date}. Read-only observation; no data submitted by Claude.

## Conventions
- **Step**: screen number in the flow (S0 = entry point, S1, S2, ...).
- **Field**: label as shown. **Req**: required / optional / unclear.
- **Needed by**: who plausibly needs it (Altitude / PSP / bank partner / law). Mark `?` if a guess.
- **Dup**: step ids where the same data is asked again.
